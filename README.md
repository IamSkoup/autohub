# AutoHub AI

Автомобильный веб сервис на Next.js: каталог реальных марок и моделей, поиск, страницы автомобилей, сравнение, избранное, демонстрационный раздел предложений и AI подбор через серверный Gemini API.

## Возможности

- Каталог с пагинацией, серверными фильтрами, сортировкой и переключением сетки/списка.
- Широкий перечень марок из России, Европы, Азии и Америки. Количество моделей считается по данным, а не задаётся рекламным числом.
- Подробные страницы известных поколений. Неподтверждённые характеристики хранятся как `null` и не показываются как факты.
- Глобальный поиск с подсказками, страницы брендов, популярные запросы.
- AI подбор: извлечение требований → кандидаты из каталога → Gemini → проверка структурированного ответа и ID.
- Сравнение до четырёх автомобилей, избранное и история запросов в `localStorage`.
- Демонстрационные объявления с фильтрами. Они явно обозначены как вымышленные, не являются предложениями продавцов.
- JSON/CSV импорт с проверкой обязательных полей и удалением дубликатов.

## Технологии

Next.js App Router, React, TypeScript, модульный CSS, Zod, серверный REST вызов Gemini. Данные каталога доступны через `CarRepository`; UI не импортирует весь каталог.

## Структура

```text
src/app/               страницы, SEO и API routes
src/components/        интерфейс и клиентское состояние
src/data/              марки, проверенные поколения, демо предложения
src/services/          CarRepository и популярность
src/ai/                промпт, извлечение требований, Gemini
src/lib/               общие утилиты
src/types/             типы данных
data/cars/             импортированные JSON по маркам
scripts/import-cars.mjs импорт JSON/CSV
```

## Запуск

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

На Windows можно скопировать файл вручную и использовать `npm.cmd`. Откройте `http://localhost:3000`. Без ключа AI сообщает о недоступности, остальные разделы работают.

## Переменные окружения

```env
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.8-flash
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

`GEMINI_API_KEY` используется только в серверном `src/ai/gemini.ts`. Подробная настройка для новичка — в [AI_SETUP.md](AI_SETUP.md).

## Добавление автомобилей и марок

Список марок и имён моделей находится в `src/data/brands.ts`. Проверенные поколения — в `src/data/curated.ts`. Там намеренно не выводятся технические данные по одному названию модели: характеристики зависят от рынка, года и модификации.

Для массового импорта подготовьте массив JSON или CSV с заголовками `brand,model,generation,yearStart,...`. Обязательны `brand` и `model`; остальные поля можно оставить пустыми. Пример:

```json
[{"brand":"Toyota","model":"RAV4","generation":"XA50","yearStart":2018,"body":"Кроссовер","country":"Япония"}]
```

```bash
npm run import-cars -- ./my-cars.json
# или
npm run import-cars -- ./my-cars.csv
```

Импорт создаёт файлы в `data/cars/{brand}.json`, отклоняет записи без марки или модели и убирает повторяющиеся ID. Перед импортом большого внешнего датасета проверьте лицензию и точность данных. После импорта перезапустите сервер. Для фотографий используйте только изображение конкретной модели с правом публикации; иначе UI покажет нейтральную иллюстрацию.

## Масштабирование

Страницы обращаются к `src/services/car-repository.ts`, а браузер получает только текущую страницу результатов. Для PostgreSQL, Supabase или Firebase замените реализацию методов репозитория, сохранив их контракт. Для миллионов записей перенесите фильтрацию и полнотекстовый поиск в базу и добавьте индекс по марке, модели и поколению. Счётчики популярности и rate limit сейчас находятся в памяти процесса; в продакшене с несколькими экземплярами используйте общую БД или Redis.

## Проверка и деплой

```bash
npm run typecheck
npm run build
npm run start
```

Разверните как Next.js приложение на совместимом Node хостинге. Добавьте переменные в серверные настройки платформы; `.env.local` не загружайте в репозиторий. Для sitemap и robots настройте `NEXT_PUBLIC_SITE_URL`. AI ключ и модель при деплое задаются отдельно для нужного окружения.
