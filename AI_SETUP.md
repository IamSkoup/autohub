# Подключение Gemini к AutoHub AI

Каталог, поиск, сравнение характеристик и избранное работают без API ключа. AI подбор и AI сравнение требуют ключ Gemini. На момент подготовки проекта в [официальной таблице тарифов](https://ai.google.dev/gemini-api/docs/pricing) для `gemini-3.8-flash` указан бесплатный уровень; доступность и лимиты зависят от региона и проекта. Перед запуском проверьте таблицу ещё раз.

## Шаг 1. Откройте Google AI Studio

Перейдите на [страницу API ключей Google AI Studio](https://aistudio.google.com/api-keys) и войдите в Google аккаунт.

## Шаг 2. Создайте ключ

Если ключ уже создан автоматически, скопируйте его. Иначе нажмите **Create API key**, выберите проект и скопируйте ключ. [Официальная инструкция](https://ai.google.dev/gemini-api/docs/api-key) описывает создание и ограничения доступа.

## Шаг 3. Добавьте ключ в проект

В корне проекта создайте `.env.local` по образцу `.env.example`:

```env
GEMINI_API_KEY=ваш_ключ_здесь
GEMINI_MODEL=gemini-3.8-flash
```

Не добавляйте `NEXT_PUBLIC_` к имени ключа. `.env.local` уже включён в `.gitignore`. После изменения переменных перезапустите сервер.

## Шаг 4. Установите библиотеки

Установите Node.js 20 или новее. В папке проекта выполните:

```bash
npm install
```

На Windows PowerShell, если запуск `npm.ps1` запрещён политикой, используйте `npm.cmd install`.

## Шаг 5. Запустите проект

```bash
npm run dev
```

На PowerShell при необходимости используйте `npm.cmd run dev`. Откройте `http://localhost:3000`.

## Шаг 6. Проверьте AI

Откройте `/ai`, введите конкретный запрос, например: «Семейный кроссовер с полным приводом», и нажмите **Подобрать автомобили**. Сервис сначала выбирает до 40 кандидатов из локального каталога и передаёт их Gemini. Ответ AI проверяется на сервере; модели, отсутствующие в выбранных кандидатах, отбрасываются.

Если запрос слишком общий, сервис задаст уточняющие вопросы без вызова платного или ограниченного API.

## Шаг 7. Измените инструкции AI

Системный промпт находится в [`src/ai/system-prompt.ts`](src/ai/system-prompt.ts). После изменения перезапустите сервер разработки или заново разверните приложение.

## Шаг 8. Смените модель

Поменяйте только значение `GEMINI_MODEL` в `.env.local`. Актуальные идентификаторы и бесплатный уровень сверяйте с [документацией моделей](https://ai.google.dev/gemini-api/docs/models) и [тарифами](https://ai.google.dev/gemini-api/docs/pricing). В коде нет жёстко зашитого обязательного идентификатора: значение из окружения имеет приоритет.

## Шаг 9. Разберите ошибки

- **AI пока не подключён** — переменная `GEMINI_API_KEY` отсутствует или сервер не перезапущен.
- **AI временно недоступен** — проверьте терминал сервера, ключ, доступность модели в регионе и подключение к сети.
- **Лимит бесплатного AI исчерпан** — проверьте [лимиты проекта](https://ai.google.dev/gemini-api/docs/rate-limits) в AI Studio и повторите позже.
- **Слишком много запросов** — локальная защита ограничивает клиентские AI вызовы за час. В распределённом продакшене замените счётчик в памяти на Redis или базу данных.
- **Подбор ослабил фильтры** — в каталоге нет достаточного количества записей с подтверждёнными ценами или комплектациями. Пополните данные; AI сообщает об этом пользователю.

## Шаг 10. Разверните безопасно

На Vercel, Netlify с поддержкой Next.js или собственном Node сервере добавьте `GEMINI_API_KEY` и `GEMINI_MODEL` в **серверные переменные окружения** проекта, затем выполните новый деплой. Для SEO добавьте `NEXT_PUBLIC_SITE_URL=https://ваш-домен`. Не вставляйте ключ в исходники, настройки frontend или публичные переменные. Проверьте AI запрос и отсутствие ключа в DevTools → Network и в собранном JavaScript.

Для высокой нагрузки перенесите ограничение частоты и статистику из памяти процесса в общую базу или Redis. Соблюдайте условия Google для бесплатного уровня и обработки пользовательских данных.
